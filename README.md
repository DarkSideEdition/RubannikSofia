# Эмулятор командной оболочки ОС (GUI)

Практическая работа №1 по дисциплине «Конфигурационное управление», вариант 16, этапы 1–3.

## 1. Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом на Python (tkinter, стандартная библиотека).
В окне есть область вывода и строка ввода с приглашением `пользователь@имя_VFS:/$ `.
Имя VFS (имя CSV-файла) выводится в заголовке окна и в приглашении.

Реализовано:

- **Этап 1 (REPL):** GUI, парсер команд с кавычками, сообщения об ошибках (неизвестная команда, неверные аргументы),
  команды-заглушки `ls` и `cd`, команда `exit`.
- **Этап 2 (конфигурация):** параметры командной строки `--vfs` и `--script`, отладочный вывод параметров,
  стартовый скрипт с имитацией диалога, сообщения об ошибках скрипта.
- **Этап 3 (VFS):** виртуальная файловая система загружается из CSV-файла целиком в память;
  служебные команды `vfs-info` и `vfs-tree`.

Структура репозитория:

```
src/        исходный код (emulator.py, shell.py, vfs.py, gui.py)
tests/      автотесты (unittest) и bat-скрипты проверки запуска
scripts/    стартовые скрипты эмулятора
vfs/        примеры VFS в формате CSV
run.sh, run.bat   запуск эмулятора
```

## 2. Описание функций и настроек

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к CSV-файлу с VFS. Если не задан, используется пустая VFS с именем `vfs` |
| `--script PATH` | путь к стартовому скрипту |
| `--help` | справка по параметрам |

При запуске в окно выводятся все заданные параметры (отладочный вывод).
Если CSV-файл не удалось загрузить, выводится сообщение об ошибке и эмулятор продолжает работу с пустой VFS.

### Стартовый скрипт

Текстовый файл (UTF-8), по одной команде в строке. Пустые строки и строки, начинающиеся с `#`, пропускаются.
Команды выполняются последовательно, на экране отображается и ввод (с приглашением), и вывод.
Ошибочная строка пропускается, выводится сообщение вида `Ошибка в скрипте (строка N): ...`,
в конце сообщается число ошибок. Команда `exit` в скрипте закрывает окно. Если `exit` нет,
после скрипта эмулятор продолжает работу в интерактивном режиме.

### Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [аргумент]` | заглушка: выводит имя команды и аргументы; более одного аргумента - ошибка |
| `exit` | закрывает окно; аргументы не принимает |
| `vfs-info` | служебная: имя, источник, число каталогов и файлов, объём данных VFS |
| `vfs-tree` | служебная: дерево всей VFS |

Парсер учитывает одинарные и двойные кавычки: `ls "my dir" 'другой каталог'` даёт два аргумента.
Ошибки: `команда не найдена`, `слишком много аргументов`, `команда не принимает аргументов`, `незакрытая кавычка`.

### Формат VFS (CSV)

Первая строка - заголовок. Столбцы:

| Столбец | Описание |
|---|---|
| `path` | полный абсолютный путь элемента, начинается с `/`; так задаётся вложенность |
| `type` | `dir` (каталог) или `file` (файл) |
| `encoding` | для файлов: `text` (по умолчанию) или `base64` (двоичные данные); для каталогов пусто |
| `content` | содержимое файла; запятые, кавычки и переносы строк экранируются по правилам CSV |

Родительские каталоги, не указанные явно, создаются автоматически. Повтор пути файла, неизвестный тип,
неверный base64, относительный путь и `..` в пути - ошибки с указанием номера строки CSV.
Все данные хранятся в памяти, файл VFS не изменяется и не распаковывается на диск.

```csv
path,type,encoding,content
/readme.txt,file,text,"Текст, с запятой"
/docs,dir,,
/docs/pixel.png,file,base64,iVBORw0KGgo=
/a/b/c/deep.txt,file,text,вложенный файл
```

## 3. Сборка и запуск тестов

Сборка не требуется. Нужен Python 3.8+ с tkinter (входит в стандартную установку на Windows и macOS;
в Debian/Ubuntu: `sudo apt install python3-tk`).

Запуск эмулятора:

```
run.bat --vfs vfs\deep.csv --script scripts\start_vfs.txt        (Windows)
./run.sh --vfs vfs/deep.csv --script scripts/start_vfs.txt         (Linux/macOS)
```

Автотесты (без окна):

```
python -m unittest discover -s tests -v
```

Скрипты проверки параметров запуска (откроют окна; после просмотра закройте окно или введите `exit`):

| Скрипт | Что проверяет |
|---|---|
| `tests\test_valid.bat` | корректные параметры: без параметров, `--vfs`, `--script`, оба, `--help` |
| `tests\test_errors.bat` | ошибки в стартовом скрипте, неизвестный параметр |
| `tests\test_missing.bat` | несуществующие пути, параметр без значения |
| `tests\test_vfs.bat` | VFS: минимальная, несколько файлов, 3+ уровня, битые CSV |
| `tests\test_all.bat` | автотесты unittest |

Стартовый скрипт `scripts/start_vfs.txt` выполняет все реализованные команды с примерами ошибок.

## 4. Примеры использования

Запуск `run.bat --vfs vfs\deep.csv --script scripts\start_vfs.txt` (3+ уровня вложенности, заголовок окна:
`Эмулятор оболочки - VFS: deep.csv`):

```

user@deep.csv:/$ cd "/path with spaces"
cd: аргументы ['/path with spaces']
user@deep.csv:/$ vfs-info
VFS:        deep.csv
Источник:   vfs/deep.csv

Объём:      56 байт
user@deep.csv:/$ vfs-tree
```

Битый CSV (`--vfs vfs/broken_type.csv`):

```
Параметры эмулятора:
  VFS путь:          vfs/broken_type.csv
  Стартовый скрипт:  (не задан)
Ошибка VFS: строка 3: неизвестный тип 'folder'
Эмулятор запущен с пустой VFS.
```

Интерактивная работа: ввод `ls "my dir" 'другой каталог'` и Enter выводит аргументы,
`cd a b` - ошибку `слишком много аргументов`, `exit` - закрывает окно.
