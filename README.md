# depviz

Инструмент визуализации графа зависимостей пакетов **Alpine Linux (apk)**.
Практическая работа №2 по дисциплине «Конфигурационное управление»,
вариант 16. Менеджеры пакетов и сторонние библиотеки не используются:
только стандартная библиотека Python 3.9+.

## Возможности

- настройки читаются из CSV-файла;
- индекс репозитория (`APKINDEX.tar.gz`) скачивается по URL и разбирается
  вручную; зависимости вида `so:...`, `cmd:...` приводятся к именам пакетов
  через поля `provides`;
- граф строится обходом в глубину **без рекурсии**, с ограничением глубины
  и фильтром по подстроке, циклы обнаруживаются и выводятся;
- тестовый режим: репозиторий описывается файлом, пакеты - `A`, `B`, ...;
- режим обратных зависимостей;
- вывод: Mermaid-описание (`.mmd`), изображение SVG, ASCII-дерево.

## Конфигурационный файл (CSV)

Формат строк: `ключ,значение`. Первая строка `key,value` необязательна.

| Ключ         | Обяз. | По умолчанию | Описание                                  |
|--------------|-------|--------------|-------------------------------------------|
| `package`    | да    | -            | имя анализируемого пакета                 |
| `repository` | да    | -            | URL репозитория или путь к тестовому файлу|
| `test_mode`  | нет   | `false`      | `true` - `repository` это путь к файлу    |
| `output`     | нет   | `graph.svg`  | имя файла SVG (рядом создаётся `.mmd`)    |
| `ascii_tree` | нет   | `false`      | вывести зависимости ASCII-деревом         |
| `max_depth`  | нет   | `3`          | максимальная глубина (целое, >= 0)        |
| `filter`     | нет   | пусто        | пакеты с этой подстрокой в имени пропускаются |
| `reverse`    | нет   | `false`      | показать обратные зависимости             |

Булевы значения: `true/false`, `1/0`, `yes/no`, `да/нет`.
URL указывается на каталог репозитория, например
`https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64`.

## Тестовый репозиторий

Одна строка - один пакет: `A: B C` (пакет A зависит от B и C).
Имена - только большие латинские буквы.

## Запуск

```
python -m depviz <config.csv> [--show-config] [--direct]
```

- `--show-config` - вывести параметры в формате ключ-значение (этап 1);
- `--direct` - вывести только прямые зависимости (этап 2) или, при
  `reverse,true`, пакеты, напрямую зависящие от заданного (этап 4).

Windows (cmd): `run.bat examples\config_test.csv --show-config`
Linux/macOS: `make run`

## Тесты

Windows (cmd):

```
set PYTHONPATH=src
python -m unittest discover -s tests -v
```

Linux/macOS: `make test`

## Примеры (каталог `examples`)

```
run.bat examples\config_test.csv --show-config   :: обычный граф
run.bat examples\config_cycle.csv                :: циклы и самозависимость
run.bat examples\config_reverse.csv              :: обратные зависимости
run.bat examples\config_limited.csv              :: глубина 2 и фильтр "E"
run.bat examples\config_test.csv --direct        :: прямые зависимости
run.bat examples\config_bad.csv                  :: обработка ошибок
run.bat examples\config_alpine.csv               :: реальный репозиторий
```

Пример вывода для `config_cycle.csv`:

```
A
`-- B
    `-- C
        |-- A (цикл)
        `-- D
            `-- D (цикл)
Циклическая зависимость: A -> B -> C -> A
Циклическая зависимость: D -> D
```
